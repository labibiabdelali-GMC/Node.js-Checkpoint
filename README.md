# Node.js Checkpoint

Simple Node.js exercises, one file per task.

## Setup

```bash
npm install
```

## Tasks

| # | File | Run | What it does |
|---|------|-----|--------------|
| 1 | `hello-world.js` | `node hello-world.js` | Prints "HELLO WORLD" |
| 2 | `server.js` | `node server.js` | Server on http://localhost:3000 showing `<h1>Hello Node!!!!</h1>` |
| 3 | `file-system.js` | `node file-system.js` | Creates `welcome.txt` ("Hello Node") and logs the content of `hello.txt` |
| 4 | `password-generator.js` | `node password-generator.js` | Logs a random password (uses `generate-password`) |
| 5 | `email-sender.js` | `node email-sender.js` | Sends an email to yourself (uses `nodemailer`) |

## Note for task 5

Put your own email and a Gmail [App Password](https://myaccount.google.com/apppasswords) in `email-sender.js` before running it.
Remove them again before pushing to GitHub.
